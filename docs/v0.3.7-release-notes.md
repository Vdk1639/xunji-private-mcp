# v0.3.7 发布说明

## 发布时间
2026-11-22

## 更新内容

### 文档改进

1. **get_training 工具说明增强**
   - 在工具文档中明确说明 lite 模式的限制
   - 提示用户写入后必须用 `include_full_data=true` 验证
   - 说明这是上游 API 行为,MCP 无法修复

2. **README 新增食物搜索功能说明**
   - 新增独立章节说明食物搜索功能配置要求
   - 明确指出 `search_official_food` 工具需要单独的 `XUNJI_FOOD_SEARCH_KEY`
   - 区分普通饮食操作和食物搜索的凭据需求

## 回应测试报告

根据「训记MCP功能测试报告(验收版)」:

### ✅ 已明确的事实

1. **食物搜索功能存在**
   - `search_official_food` 工具已在代码中完整实现
   - 该工具需要单独的搜索凭据配置
   - 测试环境可能未配置 `XUNJI_FOOD_SEARCH_KEY`,导致工具未显示

2. **lite 模式问题**
   - 上游训记 API 的行为特性,非 MCP 缺陷
   - 已通过文档明确说明,指导用户正确使用

3. **饮食模板功能**
   - v0.3.6 已完整实现
   - 本版本未涉及此功能

### 🚫 不实现的功能

- **delete_training**: 按项目维护者要求,不添加此功能

## 验证通过

所有 29 个测试用例通过:
- 训练数据读写
- 官方计划查询
- 饮食记录和模板
- 自定义食物
- 身体数据
- Agent 模板同步
- 多凭据隔离
- HTTP 传输安全

## 配置示例

### 完整功能配置 (包含食物搜索)

```json
{
  "mcpServers": {
    "xunji": {
      "command": "uvx",
      "args": ["xunji-private-mcp"],
      "env": {
        "XUNJI_TRAIN_KEY": "xjllm_...",
        "XUNJI_FOOD_KEY": "xjfood_...",
        "XUNJI_FOOD_SEARCH_KEY": "搜索专用Key",
        "XUNJI_BODY_KEY": "xjbody_...",
        "XUNJI_AGENT_TEMPLATE_KEY": "xjtpl_..."
      }
    }
  }
}
```
